# Sistema Bancario Multi-Banco

Sistema de gestión bancaria con transferencias interbancarias y persistencia de datos.

##  Actualizaciones Recientes
- **Sistema multi-banco**: Soporte para MazeBank y PacificBank
- **Transferencias interbancarias**: Con comisión del 1%
- **Nueva UI para transferencias**: Formulario integrado
- **Persistencia de datos**: Todos los datos se guardan en localStorage

##  Funcionalidades
-  Creación de cuentas en diferentes bancos
-  Depósitos y transferencias
-  Transferencias entre bancos
-  Eliminación de cuentas
-  Visualización de todas las cuentas

## Tecnologías
- HTML, CSS, JavaScript
- LocalStorage para persistencia
